Учебный скрипт на Python, который определяет текущую ОС, собирает параметры внутри нее и записывает результат в JSON-файл.
Для чего необходим ?
1. Определяет, на какой ОС запущен код (Linux, macOS, Windows)
2. Собирает набор параметров про ОС, железо и окружение Python
3. Сохраняет все в файле JSON
4. Печатает то же самое в консоль
Для запуска необходимо иметь версию Python 3.8 или новее, а так же подключить библиотек psutil(pip install psutil). После запуска рядом со скриптом появится файл JSON
Собираемые параметры:
   1. Название системы(platform.system())
   2. Версия релиза/ядра(platform.release())
   3. Подробная версия(platform.version())
   4. Архитектура процессора(platform.machine())
   5. Имя компьютера в сети(socket.gethostname())
   6. Кто залогинен на данный момент(getpass.getuser())
   7. Версия питона (platform.python_version())
   8. Модель процессора (platform.processor())
   9. Количество логических ядер(psutil.cpu_count())
   10. Количество физических ядер(psutil.cpu_count(logical = False))
   11. Количество оперативки в гигабайтах(psutil.virtual_memory().total)
   12. MAC-адрес в привычном виде(uuid.getnode())
Для реализации данной программы понадобился всего один внешний модуль - psutil. Потому что через platform нельзя узнать количество физических ядер. ключевой фактор это то, что psutil сам разбирается с системными вызовами для каждой ОС.
